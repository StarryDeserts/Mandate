# Mandate Account

Mandate Account is a programmable authorization account on Robinhood Chain testnet: a user's on-chain mandate lets an AI session key only PROPOSE tokenized-stock swaps; the account blocks unsafe actions on-chain and executes safe ones, with no AI custody.

> **DISCLAIMER:** Demo-grade, testnet only. Uses a SignedDemoPriceFeed (not a production oracle). Not investment advice.
